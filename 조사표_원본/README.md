# 조사표 원본 (수집용)

여기 있는 파일은 **작업 중간 산출물**입니다. 분석·개발에 쓰는 최종 데이터는
프로젝트 루트의 `시흥캠퍼스_식당카페_조사표_통합.xlsx` 하나뿐입니다.

| 파일 | 무엇 |
|---|---|
| `시흥캠퍼스_식당카페_조사템플릿.xlsx` | 빈 템플릿. 새로 조사할 때 복사해서 씁니다. |
| `시흥캠퍼스_식당카페_조사표_강권재.xlsx` | 1차 조사 분량 (한식·중식·일식) |
| `시흥캠퍼스_식당카페_조사표_류성환.xlsx` | 1차 조사 분량 (양식·치킨·피자·족발·보쌈) |
| `시흥캠퍼스_식당카페_조사템플릿_카페디저트 (최지원).xlsx` | 1차 조사 분량 (카페·디저트) |
| `*.xlsx.bak` | 엑셀이 남긴 백업. git에서 무시됩니다. |

## 통합 파일과의 관계

개인 조사표 3개의 1차 분량(46곳)은 이미 통합 파일에 들어가 있습니다. 이후
2차 캡처에서 나온 66곳은 개인 조사표를 거치지 않고 통합 파일에 바로
반영했으므로, **개인 조사표는 통합 파일보다 오래된 상태**입니다.

소분류는 네 파일 모두 배달의민족 카테고리 기준으로 맞춰져 있어, 이
템플릿으로 추가 조사를 해도 통합 파일에 그대로 붙일 수 있습니다. 기준은
13종에서 **14종(도시락 추가)** 으로 늘었습니다. 2차 수집에 도시락 매장이
포함되어 있어 되살린 분류입니다.

## 캡처 추출 결과

배민 앱 화면 캡처에서 뽑아낸 매장·메뉴 구조화 결과는 캡처 폴더 안에 있습니다.

- `data/capture_GJ/extracted.json` (15건) — **1차** 캡처, 매장번호 1~15
- `data/capture_GJ_v2/extracted.json` (32건) — 2차
- `data/dossier sans titre/extracted.json` (20건) — 2차
- `data/최지원카페2차/extracted.json` (22건) — 2차

2차 폴더 3개의 기록은 합해서 74건이지만 통합 파일에 새로 들어간 매장은
66곳이 맞습니다. 차이 8건의 내역: 1차 조사 매장을 다시 캡처한 재캡처 4곳,
폴더 간 중복 기록 3건, 통합 파일에 반영하지 않은 1곳(샐러디 배곧점).
