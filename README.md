# 모여밥

서울대학교 시흥캠퍼스 구성원이 같은 음식점에서 함께 주문할 사람을 찾고,
모집에 참여할 수 있도록 만드는 웹앱입니다.

## 바로 확인하기

- 구현 화면: [http://localhost:3000](http://localhost:3000)
- GitHub 저장소: [famegon/moyeobap](https://github.com/famegon/moyeobap)
- 제품 범위와 세부 결정: [모여밥 작업 지침서](AGENTS.md)

아직 공개 배포된 사이트는 없습니다. 구현 화면 주소는 프로젝트를 내 컴퓨터에서
실행한 동안에만 열립니다. 현재 화면의 음식점과 모집 정보는 흐름을 확인하기
위한 예시 데이터입니다.

## 왜 만들고 있나요?

약 40명이 함께 생활하는 공간에서 점심이나 카페 주문을 함께할 사람을 찾으려면
직접 물어보거나 Slack 대화를 계속 확인해야 합니다. 누가 같은 음식점을 원하는지,
몇 명이 모였는지, 언제 모집이 끝나는지 한눈에 알기 어렵고 주문을 제안하는
사람에게 부담도 몰립니다.

모여밥은 음식점별 공동주문 모집과 참여 현황을 한곳에 보여줘 이 과정을 더
간단하게 만드는 것을 목표로 합니다. 메뉴를 직접 고르거나 결제하는 서비스는
아니며, 함께 주문할 사람을 모으는 데 집중합니다.

## 사용자는 어떻게 이용하나요?

1. Slack 공지에 있는 모여밥 링크를 눌러 실시간 모집을 확인합니다.
2. 원하는 음식점의 모집을 열어 마감 시간, 참여 인원과 매장 정보를 확인합니다.
3. 참여하려면 Slack 계정으로 로그인한 뒤 모집에 참여합니다.
4. 원하는 모집이 없다면 음식점과 마감 시간을 골라 새 모집을 만듭니다.
5. 모집이 끝나면 확정된 참여자들과 Slack에서 실제 주문을 논의합니다.

## 지금 어디까지 진행됐나요?

현재는 사용자가 위 과정을 자연스럽게 따라갈 수 있는지 화면을 직접 눌러보며
점검하고 있습니다. 현황판, 모집 상세, 새 모집 화면을 만들어 두었지만 최종
디자인은 아닙니다. 불편하거나 빠진 부분을 발견하면 화면 구성뿐 아니라 앞서
정한 사용 순서도 다시 고칩니다.

화면 구성이 안정되면 색상, 글꼴, 버튼과 카드 모양 같은 공통 디자인을 정하고
실제 UI를 다듬을 예정입니다.

## 현재 화면에서 확인할 수 있는 것

### 실시간 현황판

- 로그인하지 않아도 모집 목록과 현재 참여 인원 확인
- 전체 모집과 내가 참여한 모집 전환
- 점심과 카페 모집 전환
- 음식점·카테고리 검색과 마감이 가까운 순서 확인
- 카드에서 바로 참여하거나 상세 화면으로 이동

### 모집 상세

- 마감 시간, 참여 인원, 배달 예상 시간과 최소 주문금액 확인
- 매장 정보와 대표메뉴 최대 5개 확인
- 참여와 참여 취소
- 참여 후 참여자 이름과 현재 모집 관리자 확인
- 관리자가 빠질 때 참여 순서에 따른 자동 관리자 변경 확인
- 모집 마감 뒤 Slack으로 이어지는 위치 확인

### 새 모집 만들기

- 음식점, 점심·카페 구분과 모집 마감 시간 입력
- 같은 음식점의 진행 중인 모집 확인
- 같은 마감 시간의 중복 모집 방지
- 모집 생성자를 첫 참여자이자 최초 관리자로 등록

## 아직 연결되지 않은 기능

| 항목 | 현재 상태 |
|---|---|
| 음식점·모집 데이터 | 화면 확인용 예시 데이터 사용 |
| 참여·관리자 변경·새 모집 | 현재 브라우저에만 임시 저장 |
| 새로고침 후 변경사항 | 초기화됨 |
| 여러 사용자의 실시간 참여 | 연결되지 않음 |
| Slack 로그인 | 동작 위치만 확인하는 가짜 로그인 |
| 모집 마감 자동 처리 | 연결되지 않음 |
| Slack 알림과 참여자 대화 | 구체적인 연동 방식 결정 전 |

## 내 컴퓨터에서 실행하기

Node.js 22.13 이상과 npm이 필요합니다.

```bash
npm install
npm run dev
```

실행 후 [http://localhost:3000](http://localhost:3000)을 브라우저에서 엽니다.
서버를 종료하려면 실행한 터미널에서 `Ctrl+C`를 누릅니다.

배포 전에 아래 명령으로 빌드 오류를 확인할 수 있습니다.

```bash
npm run build
```

## 배포 계획

화면 구성이 안정되면 GitHub 저장소를 Vercel에 연결해 팀원이 별도 설치 없이
접속할 수 있는 공개 주소를 만들 예정입니다. 공개 배포가 완료되면 README
상단의 구현 화면 주소를 실제 배포 주소로 교체합니다.

## 프로젝트 구조

```text
moyeobap/
├─ app/
│  ├─ components/        공통 헤더, 모집 카드와 알림
│  ├─ lib/               예시 음식점·모집 데이터와 타입
│  ├─ recruitments/
│  │  ├─ [id]/page.tsx   모집 상세
│  │  └─ new/page.tsx    새 모집 만들기
│  ├─ page.tsx           실시간 현황판
│  ├─ prototype-context.tsx  화면 간 공유되는 임시 상태
│  ├─ globals.css        전체 화면 스타일
│  └─ layout.tsx         공통 화면 틀과 페이지 정보
├─ public/                공유 이미지와 정적 파일
├─ data/                  수집 중인 음식점·메뉴 자료
├─ package.json
├─ next.config.ts
└─ README.md
```

현재 화면에 보이는 예시 음식점과 모집은 `app/lib/prototype-data.ts`에 있습니다.
